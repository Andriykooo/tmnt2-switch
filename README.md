# TMNT 2: Battle Nexus — Nintendo Switch port

A native homebrew port of *Teenage Mutant Ninja Turtles 2: Battle Nexus* (PC, 2004) for the Nintendo Switch.

It is built from [xntrz/tmnt2](https://github.com/xntrz/tmnt2), a reimplementation of the PC game. That project's published web build (`index.wasm`) is recompiled to C with **wasm2c**. This repository supplies a host runtime that replaces the Emscripten JavaScript glue with native code:

| Glue in the browser | Runtime on Switch |
|---|---|
| WebGL | OpenGL ES 3 (Mesa) |
| EGL / canvas | the libnx window |
| OpenAL | openal-soft |
| HTML5 Gamepad API | Joy-Con / Pro Controller |
| MEMFS / IDBFS / WorkerFS | files on the SD card |

**No game data, generated code or binaries are included.** You need your own copy of the PC game.

## Layout

- `port/rt.h`: runtime interface. It covers export names, memory helpers and the platform hooks.
- `port/rt_core.c`: invoke_*/longjmp, time, EM_ASM dispatch, the WorkerFS async queue and the main loop.
- `port/rt_fs.c`: file syscalls mapped to host files.
  - The game assets mount at `/wfs/`.
  - Saves go to `/ifs/` → `<game dir>/ifs/`.
- `port/rt_gl.c`: the WebGL imports mapped 1:1 onto GLES3.
- `port/rt_display.c`: fake EGL handles, plus swap → platform frame.
- `port/rt_input.c`: presents one W3C "standard" gamepad. It also sends Escape for pause.
- `port/rt_al_openal.c`: OpenAL imports mapped onto openal-soft.
- `port/switch_main.c`: the Switch entry point. It handles EGL setup, the button layout and the game thread.
- `port/pc_main.c`, `port/rt_headless.c`, `port/rt_al_null.c`: a headless Windows test harness.
- `port/imports_gen.c`: weak logging stubs for every import, generated by `tools/gen-stubs.js`.
- `port/imports-dump.tsv`, `port/exports-emasm.txt`: the JS bodies of the imports and the EM_ASM table, captured from the web build. They serve as reference.

## Building

Requirements:
- [devkitPro](https://devkitpro.org) with `switch-dev`, `switch-mesa`, `switch-openal-soft` and `switch-sdl2`
- [WABT](https://github.com/WebAssembly/wabt) 1.0.42
- [SIMDe](https://github.com/simd-everywhere/simde)

Steps:
1. Download the NA web build `index.wasm` from https://xntrz.github.io/tmnt2-play/ into `wasm/`.
2. Generate the C code:
   ```bash
   wasm2c wasm/index.wasm -n tmnt2 -o gen/tmnt2.c
   ```
3. Generate the import stubs:
   ```bash
   node tools/gen-stubs.js gen/tmnt2.h port/imports-dump.tsv port/imports_gen.c
   ```
4. Put a 256×256 JPEG at `build/icon/icon.jpg`.
5. In the devkitPro MSYS2 shell, run `./build-switch.sh`. The first compile of `gen/tmnt2.c` takes about 50 minutes.

## Installing

Copy everything to `sdmc:/switch/tmnt2/`:
- `tmnt2.nro`
- from the PC game: `TMNT.DAT`, `TMNTE.DAT`, `TMNT2V00–05.DAT`, `WaveData.bin`, `SeData.bin`, `TrSeData.bin`
- `Common/Fonts/MainFont.met` and `Common/Touch/Touch.lpac`, from the web build's `index.data`

Launch it through title override (hold **R** while starting a game) so it gets full RAM.

The game writes a log to `sdmc:/switch/tmnt2/log.txt`.

## Controls

| Button | Action |
|---|---|
| A | attack A / OK |
| X | attack B |
| Y | dash |
| L | shuriken |
| B | jump / back |
| R or ZR | guard |
| R + X | grab, then X to throw |
| ZL | switch turtle |
| + | pause |
| L3 | gauge |
| R3 | camera |
| + and − together | quit |
